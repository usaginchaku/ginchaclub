# ぎんちゃくらぶ

オリジナル曲「POYO POP」に合わせて「うさぎんちゃく」をタップする、小さな音遊びサイト。

公開サイト： https://usaginchaku.github.io/ginchaclub/

## 起動

Node.js が入った環境で `npm start` を実行し、http://127.0.0.1:4173 を開きます。
依存パッケージのインストールやビルドは不要です。`file://` では音声の fetch が利用できないため、HTTP で開いてください。

## 操作

- 「あそぶ」またはキャラクターをタップして開始。再生ボタンで一時停止・再開。
- 8つのパッドで演奏。上段は A / S / D / F、下段は G / H / J / K でも演奏できます。
- タップした一音目から、キックと同じ4分音符の位置に合わせて発音します。128 BPMで次の拍まで最大約475ミリ秒待ちます（機器の出力遅延を除く）。パッドの小さな点は発音待ちです。表示は音声出力時刻に追従し、対応ブラウザーでは `getOutputTimestamp()` で出力遅延も考慮します。
- 「ぴこ」「ぱち」「ころころ」「しゅわ」を追加。「ころころ」は短い転がる音とともに、足もとから小さなうんちが3つ転がります。ループにも記録できます。演出の同時表示数と寿命を制限し、動きを減らす設定にも対応します。
- 「くりかえす」をオンにすると、その発音位置を記録して4小節ごとに再生します。同じ位置の同じ音は重ねず、違う音は同時に鳴らせます。
- ループはこのページを開いている間だけ保持。オフにしてもパターンは残り、「消す」でリセットします。
- ページを離れると一時停止し、戻って再生ボタンを押すと続きから再開します。
- キーボードの Space はフォーカス中のボタンを操作し、ボタン外では再生・停止になります。
- OS の「視差効果を減らす / アニメーションを減らす」に対応します。

## 曲

`assets/audio/poyo-pop.wav`：44.1 kHz / 16-bit / stereo、60秒の正確なループ。

`assets/audio/poyo-pop.mp3`：192 kbps、視聴・保存用。

128 BPM / F major / 32小節。4小節イントロ → 8小節フック → 4小節ブレイク → 4小節ビルド → 8小節フック → 4小節ターンアラウンド。
コードは Fmaj7、C(add9)/E、Dm7、Bbmaj7。跳ねるFM風プラック、ベル、丸いベース、キック、クラップ、ハイハットを合成しています。

`tools/compose.py` に全ての音符・音色・編曲を記述。Python + NumPy + FFmpeg で `npm run compose` を実行すると再生成できます。固定乱数シードで再現可能です。外部サンプル、音声生成API、既存曲の録音は使いません。

## 構成・検証

- `src/audio.js`：Web Audio の再生クロック・タップ音・ループ。
- `src/rhythm.js`：拍・ループ位置・曲の展開。
- `src/sounds.js`：8音の音色パラメーター、キー、色、表情の対応。
- `src/scene.js`：提供された資料をもとにCanvasで描いた「うさぎんちゃく」と音に連動する動き。白い巾着・耳・手足・ピンクのひもとリボン・表情を描画します。
- `src/app.js`：操作、音量、ダイアログ、ページ非表示時の停止。
- `server.mjs`：localhost 限定、音声 Range リクエスト対応の静的サーバー。
- `npm test`：ループ境界・連打の上限・曲の展開のテスト。
- `node tools/check-http.mjs`：起動済みサーバーの音声取得・Range・MP3を検証。
- `assets/audio/audio-check.json`：生成音声の数値検証。

## 公開・更新

GitHub Pagesで配信します。`npm test` と `npm run build` が成功したmainブランチの変更だけを、GitHub Actionsから公開します。ビルドは `tools/public-files.mjs` の10ファイルと `.nojekyll` を `dist/` にまとめます。ワークスペース全体は配信しません。

公開後は `node tools/check-public.mjs https://usaginchaku.github.io/ginchaclub/` でHTTPS・全公開ファイルのSHA-256・非公開対象パスの404を確認できます。保護設定と制約、ロールバック手順は [SECURITY.md](SECURITY.md) に記載しています。
